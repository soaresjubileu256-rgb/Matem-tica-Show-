# Fontes do Matemática Show

Guardadas no próprio app pra abrir mais rápido, funcionar sem internet e não enviar dados pro Google.
São fontes "variáveis" (um arquivo cobre todos os pesos), só com o alfabeto latino.

| Arquivo | Fonte | Autor | Licença |
|---|---|---|---|
| `inter.woff2` | Inter | Rasmus Andersson | SIL Open Font License 1.1 |
| `fraunces.woff2` | Fraunces | Undercase Type (Phaedra Charles, Flavia Zimbardi) | SIL Open Font License 1.1 |
| `jetbrains-mono.woff2` | JetBrains Mono | JetBrains | SIL Open Font License 1.1 |

Baixadas do Google Fonts. A licença SIL OFL 1.1 permite usar, guardar e distribuir as fontes junto com o app:
https://openfontlicense.org
